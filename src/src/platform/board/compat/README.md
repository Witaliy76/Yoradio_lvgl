# compat — временные имена ST7701_* и TS_*

Author: Witaliy76 - https://github.com/Witaliy76

Короткий мост. Правила выбора платы и Custom Wiring — в [Board Contract](../README.md).

`legacy_macros.h` не хранит ни одного своего номера GPIO. Его подключает `src/src/core/options.h` после `board_select.h`. Направление одно: заводской профиль → `kWiring` → эти имена → старые драйверы.

## Какие имена есть

Дисплей, 24 имени, все читают `yoradio::kWiring.display`:

`ST7701_B0`…`ST7701_B4`, `ST7701_G0`…`ST7701_G5`, `ST7701_R0`…`ST7701_R4`, `ST7701_HSYNC`, `ST7701_VSYNC`, `ST7701_DE`, `ST7701_PCLK`, `ST7701_CS`, `ST7701_SCK`, `ST7701_SDA`, `ST7701_BL`.

Тач, 4 имени, читают `yoradio::kWiring.touch`:

`TS_SDA`, `TS_SCL`, `TS_INT`, `TS_RST`.

`ST7701_BOOT_ORIENTATION_180` здесь нет. Это политика ориентации в `src/myoptions.h`, не пины.

Если в `myoptions.h` осталось старое `#define ST7701_*` или `TS_*`, заголовок останавливает сборку и просит имя `DISP_*` или `TOUCH_*`.

## Почему это выражение C++, а не число для `#if`

Каждое имя раскрывается в поле структуры, например `(yoradio::kWiring.display.data_gpio[3])`. Так переопределение Custom Wiring доходит до драйвера без второй копии таблицы.

В `#if` такое имя не число. Неизвестное препроцессору имя там становится нулём, а GPIO0 на этой плате — настоящий R4. Поэтому по `ST7701_*` и `TS_*` нельзя писать `#if`. Для отсутствия пина драйвер сравнивает 255 в обычном коде. `I2S_*` и `WAKE_PIN` в `#if` по-прежнему можно использовать именно потому, что они остались обычными макросами в `myoptions.h`.

## Когда мост убрать

S04: драйвер дисплея читает `kWiring.display` сам, имена `ST7701_*` удаляются.
S05: драйвер тача читает `kWiring.touch` сам, имена `TS_*` удаляются.

До этих этапов мост обязателен. Новый код не должен заводить ещё один слой синонимов.
