Theme file format

Use a plain-text file named theme_custom.txt, no larger than 4096 bytes. Put one key=value record on each line. Color values use six hex digits; a leading # is accepted and recommended.

Keys are case-insensitive. theme_dark accepts true or false; rail_opa_scale accepts 0–200. Blank lines and comments beginning with # are ignored.

Unknown keys and malformed lines are skipped and reported after upload. Missing color keys keep their built-in Amber Hi-Fi values.

theme_dark=true
device_background=#0D0806
panel_border=#5A422B
text_primary=#F4E7D2
accent=#D89A2B
