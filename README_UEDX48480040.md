# VIEWE UEDX48480040E-WB-A — подключение и прошивка YoRadio

Аппаратная инструкция для VIEWE UEDX48480040E-WB-A (4", 480×480): характеристики, подключение звука, сборка, прошивка и особенности платы. Описание интерфейса, тем и Web UI — в [основном README](README.md).

Это вторая плата YoRadio LVGL после [ESP32-4848S040](README_4848S040.md). Поддержка добавлена этапом S07_bis и проверена на устройстве со сборкой `0.9.434m-r2-lvgl-beta.3.09-S07bis.B014`: изображение, цвета, тач, Wi-Fi, воспроизведение с SD и звук через внешний ЦАП PCM5102. Готовых бинарников для этой платы нет: прошивка собирается из исходников.

## Что понадобится

- Плата VIEWE UEDX48480040E-WB-A.
- Кабель USB-C для разъёма **UART**.
- Внешний I2S ЦАП, например модуль PCM5102 (обязательно: своего звука на плате нет).
- Провода к разъёму на задней стороне платы.
- Активная акустика или усилитель на выходе ЦАП.
- [PlatformIO](https://platformio.org/) для сборки из исходников.

## Важное замечание об аудио

Своего аудиотракта на плате нет, и производитель не выделял выводы под звук. YoRadio выводит звук по I2S на внешний ЦАП через три линии разъёма на задней стороне платы:

- **GPIO19 и GPIO20** — линии встроенного USB ESP32-S3. Пока к разъёму **USB** ничего не подключено, они свободны.
- **GPIO48** — тактовая линия команд дисплея. После инициализации панели она переходит к I2S.

Отсюда главное правило: **разъём USB оставьте пустым**. Питание, прошивка и лог идут через разъём **UART**.

## Подключение внешнего ЦАП

На задней стороне платы стоит двухрядный разъём на 40 контактов (на схеме — J1).

> **Важно.** На шелкографии рядом с контактами напечатаны **номера GPIO** («19», «20», «48», «GND», «5V»), а не номера контактов разъёма. Подключайте по этим надписям.

| Сигнал I2S | Контакт PCM5102 | Надпись на разъёме (GPIO) | Контакт J1 по схеме |
|---|---|---|---|
| BCLK | BCK | **19** | 9 |
| LRCK / WS | LCK | **48** | 19 |
| DATA (DOUT) | DIN | **20** | 10 |
| Общий провод | GND | **GND** | 1 или 3 |
| Питание | VIN | **5V** | 2 |

Не подключайте ЦАП к надписям **«9», «10», «17»**. Это GPIO9 и GPIO10 (данные экрана G1 и G0) и GPIO17 (VSYNC экрана). ЦАП тогда получит данные изображения, и звука не будет.

Модуль PCM5102 питается от 5 В: на нём стоят свои стабилизаторы на 3.3 В. Перемычки типового модуля: FLT = L, DEMP = L, XSMT = H, FMT = L. Вывод SCK модуля соедините с GND, если на модуле нет такой перемычки. Тогда модуль сам строит свой такт по BCK.

Все три сигнала — выходы ESP32 в режиме I2S master. Прошивка не использует вход данных I2S и не выводит MCLK. Пины 19 / 48 / 20 — умолчания профиля платы. Их можно изменить в `src/myoptions.h` (`I2S_DOUT`, `I2S_BCLK`, `I2S_LRC`), но свободных GPIO на этой плате почти нет. Список занятых линий — в разделе «Справочная таблица GPIO» ниже.

После старта Serial в блоке `[HARDWARE CONFIG]` печатает `i2s-dout: 20`, `i2s-bclk: 19`, `i2s-lrc: 48`. Это значения, с которыми собрана прошивка.

## Сборка и прошивка

1. Откройте `src/myoptions.h` и выберите плату:

   ```cpp
   #define YORADIO_BOARD YORADIO_BOARD_UEDX48480040
   ```

2. Задайте `L10N_LANGUAGE`: `RU`, `EN`, `PL` или `SK`.
3. В PlatformIO выберите окружение `[env:S3_N16R8]`. Это общее окружение семейства ESP32-S3 N16R8; плату выбирает только `YORADIO_BOARD`.
4. Подключите кабель к разъёму **UART** и соберите и загрузите прошивку и файловую систему LittleFS (в PlatformIO: Upload и Upload Filesystem Image).
5. Wi-Fi и список станций настраиваются при первом запуске и через Web UI / файлы в `data/`.

Подробности сборки из исходников — в [основном README](README.md#замечание-для-сборки-из-исходников) и в `platformio.ini`.

`DISPLAY_BOOT_ORIENTATION_180` для GC9503 не поддерживается: с `true` сборка остановится с сообщением. Custom Wiring (`YORADIO_CUSTOM_WIRING`) на этой плате не проверялся.

## Готовые бинарники

Для VIEWE UEDX48480040E-WB-A готовых пакетов нет. Пакеты в [build_bin/4848S040/](build_bin/4848S040/) собраны для другой платы и на эту не подходят.

## Первый запуск

После включения YoRadio показывает загрузочный экран и пытается подключиться к сохранённой сети. Если сеть не настроена или недоступна, открывается Wi-Fi Setup / Recovery: сканирование, выбор сети, ввод пароля (для открытой сети не запрашивается) и сохранение. После сохранения устройство перезагружается и открывает Main.

Если Recovery остаётся без действий, поднимается точка доступа `yoRadioAP` (без пароля). Подключитесь к ней и продолжите настройку через Web UI по IP точки доступа.

Экраны, жесты и Web UI такие же, как на ESP32-4848S040: у обеих плат квадратный экран 480×480 и одинаковый профиль интерфейса. Описание экранов — в основном [README проекта](README.md#интерфейс), жесты — в [руководстве по ESP32-4848S040](README_4848S040.md#особенности-управления-на-esp32-4848s040).

## Особенности платы

- **Частота экрана.** Панель работает на 12 МГц (около 44 кадров в секунду): при запуске 6 МГц, после перехода на Main одно повышение до 12 МГц, во время записи во flash — 6 МГц. По паспорту панели нужно от 16 МГц, но без bounce-буфера на 16 МГц изображение сдвигается под нагрузкой, а на 10 МГц экран иногда заметно мерцал. 12 МГц проверены под нагрузкой (радио, HTTPS, записи настроек) и на холодном старте.
- **Светодиод.** RGB-светодиод платы (WS2812) висит на линии SD-карты (GPIO42) и мигает при обращении к карте. Это нормально; прошивка им не управляет.
- **Тач.** FT6336U работает в режиме опроса: линия прерывания на плате не подключена.
- **Кнопка BOOT** сидит на GPIO0, который одновременно служит линией R4 экрана, как на ESP32-4848S040. Пробуждение из Deep Sleep по BOOT (`WAKE_PIN 0`) на этой плате пока не проверялось.

## Справочная таблица GPIO

Заводская разводка VIEWE UEDX48480040E-WB-A (схема V1.3). Полная карта и подтверждения — в [профиле платы](src/src/platform/board/profiles/esp32s3_uedx48480040/README.md).

| Назначение | GPIO |
|---|---|
| Дисплей: данные B0–B4 / G0–G5 / R0–R4 | 15–11 / 10–5 / 4–0 |
| Дисплей: HSYNC / VSYNC / DE / PCLK | 16 / 17 / 18 / 21 |
| Дисплей: команды CS / SCK / SDA (3-wire) | 39 / 48 / 47 |
| Подсветка (PWM) | 38 |
| Тачскрин FT6336U: SDA / SCL | 40 / 41 |
| microSD: CS / CLK / CMD / DAT0 | 47 / 45 / 42 / 46 |
| I2S: BCLK / LRCK / DATA | 19 / 48 / 20 |
| UART (CH340): TX / RX | 43 / 44 |
| Встроенный USB: D− / D+ | 19 / 20 (заняты I2S) |
| Кнопка BOOT | 0 (совмещена с линией R4) |

Две линии используются по очереди: GPIO47 сначала передаёт команды панели, затем служит CS карты; GPIO48 сначала даёт такт команд панели, затем служит LRCK / WS для I2S. SD включается `YORADIO_SD_ENABLE` в `src/myoptions.h`; подробности — в [Storage Contract](src/src/platform/storage/README.md).
