# YoRadio RGB Panel

## Кратко о проекте

YoRadio RGB Panel — Wi-Fi интернет-радио на ESP32-S3 с сенсорным дисплеем 480×480. Интерфейс построен на LVGL 8.3: шесть страниц, доступных горизонтальным свайпом, плюс отдельные режимы для загрузки, настройки Wi-Fi, быстрого доступа к избранным станциям и заставки.

Кроме экрана устройства есть Web UI: управление воспроизведением, список станций, настройки поведения и раздел Appearance — темы, фоны Main screen и обложка текущей станции. Для звука проект рассчитан на подключение внешнего I2S ЦАП или усилителя; встроенный моно-ЦАП тоже доступен, но используется в первую очередь для проверки платы.

Проект основан на [e2002/yoradio](https://github.com/e2002/yoradio). Адаптацию для плат с RGB Panel дисплеем и развитие LVGL-интерфейса ведёт [Witaliy76](https://github.com/Witaliy76) в репозитории [Yoradio_RGB_Panel](https://github.com/Witaliy76/Yoradio_RGB_Panel).

> Публичная beta: `0.9.434m-r2-lvgl-beta.1`. Поддерживаемая плата: **ESP32-4848S040**.

## Основные возможности

- Воспроизведение интернет-радиостанций: MP3, AAC, FLAC, OGG/Vorbis, Opus.
- Шестистраничный сенсорный интерфейс на LVGL 8.3: Info, Main, Visual, Station, Weather, Settings.
- Список станций с постраничной навигацией и текущим номером позиции.
- Weather — текущая погода и прогноз (данные OpenWeatherMap).
- Visual — VU-индикатор в стиле винтажных приборов Beocord.
- Preset Temporary — быстрый доступ к 8 сохранённым станциям.
- Analog Screensaver — аналоговые часы в режиме ожидания.
- Web UI — управление плеером, список станций, настройки, Appearance, обновление прошивки.
- Station artwork — обложка для текущей воспроизводимой станции на экране Main.
- Main screen backgrounds — отдельный фон для каждой темы оформления.
- Темы Dark / Light / Custom с мгновенным переключением.
- Локализация интерфейса RU / EN / PL, выбирается при сборке.
- AI Layer — необязательный тихий информационный слой поверх музыки (см. ниже).

## Как выглядит интерфейс

Шесть страниц объединены в кольцо и переключаются горизонтальным свайпом:

```text
Info ↔ Main ↔ Visual ↔ Station ↔ Weather ↔ Settings
```

### Main

Основной экран воспроизведения: обложка станции, название станции и трека, панель управления, регулировка громкости слайдом и бегущая строка с дополнительной информацией.

![Экран Main](readme/main-screen-guide.png)

### Info

Техническая информация об устройстве: сеть и Wi-Fi, версия прошивки, чип и время работы, дисплей и LVGL, память и PSRAM. Полезен для диагностики.

![Экран Info](readme/info-screen-guide.png)

### Visual

Декоративная визуализация воспроизведения в стиле винтажных VU-индикаторов Beocord. Работает только во время проигрывания потока.

![Экран Visual](readme/visual-screen-guide.png)

### Station

Список радиостанций с вертикальным листанием, текущей позицией в списке и индикатором активной станции. Нажатие возвращает на главный экран.

![Экран Station](readme/station-screen-guide.png)

### Weather

Текущая погода, ощущаемая температура, ветер, влажность, давление, почасовой прогноз на сегодня и прогноз на ближайшие три дня.

![Экран Weather](readme/weather-screen-guide.png)

### Settings

Быстрый доступ к яркости и теме экрана, музыкальному индикатору, автовозобновлению воспроизведения, таймеру сна и настройке Wi-Fi.

![Экран Settings](readme/settings-screen-guide.png)

## Дополнительные режимы

### Preset Temporary

Экран быстрого доступа к избранным станциям. Открывается свайпом вниз от верхнего края экрана на страницах **Info, Main, Visual и Weather**. Доступно 8 слотов: короткое нажатие на заполненный слот запускает сохранённую станцию, долгое нажатие сохраняет в слот текущую станцию. Экран автоматически закрывается примерно через 15 секунд бездействия.

![Экран Preset](readme/preset-screen-guide.png)

### Screensaver

Полноэкранная заставка с аналоговыми часами, показывается в режиме ожидания. Включение, отключение и оформление настраиваются через Web UI. Выход — касание экрана.

![Экран Screensaver](readme/screensaver-guide.png)

### Display settings

Раздел Settings → Display: яркость экрана, автоматическое затемнение (Auto Dim) с задержкой и целевым уровнем яркости, выбор темы оформления.

![Настройки Display](readme/display-settings-guide.png)

### Sleep Device

Режим глубокого сна (deep sleep): экран и работа устройства полностью отключаются. Пробуждение через касание экрана **не поддерживается** — для повторного запуска нужен Reset или переподключение питания. Sleep Device выбирается как действие по окончании Sleep Timer в Settings.

![Режим Sleep Device](readme/sleep-device-guide.png)

## Web UI

Web UI доступен в браузере по адресу `http://<IP-адрес-устройства>/` — IP-адрес устройства показан на экране Info. Через Web UI доступно управление воспроизведением, список станций, настройки поведения устройства, раздел Appearance и обновление прошивки/файловой системы.

![Web UI, иконка Appearance](readme/webui-appearance-entry.png)

### Appearance

Раздел Appearance открывается новой иконкой на главной странице Web UI и объединяет три независимых блока.

#### Station Artwork

Загрузка обложки действует только для текущей воспроизводимой станции. **Choose image** выбирает файл на компьютере и показывает предпросмотр — запись на устройство ещё не происходит. **Upload to device** записывает обработанное изображение в LittleFS и привязывает его к ключу станции; после этого оно отображается на экране Main при воспроизведении этой станции. **Remove artwork** удаляет картинку для текущей станции. Перед загрузкой изображение автоматически центрируется и приводится к размеру 120×120.

![Web UI: Station Artwork](readme/webui-station-artwork-guide.png)

#### Color Theme и Custom Palette

Темы **Dark**, **Light** и **Custom** переключаются сразу и сохраняются на устройстве. Custom использует загруженную палитру `theme_custom.txt` (текстовый файл вида `key=#RRGGBB`) либо, если файл не загружен, встроенную палитру **Amber Hi-Fi**. **Choose file** выбирает `theme_custom.txt` на компьютере, **Upload & Apply** загружает и сразу применяет палитру, **Remove custom palette** удаляет пользовательскую палитру и возвращает Amber Hi-Fi.

![Web UI: Color Theme](readme/webui-color-theme-guide.png)

#### Main Screen Backgrounds

Для фона экрана Main предусмотрено три независимых слота — Dark, Light и Custom, каждый привязан к своей теме. **Choose image** только выбирает и подготавливает предпросмотр, запись происходит по **Upload to device**. **Remove image** удаляет фон только выбранного слота, не переключая активную тему. Загрузка фона сама по себе тему не меняет — переключение темы выполняется отдельно в блоке Color Theme. Изображения приводятся к размеру 480×480.

![Web UI: Main Screen Backgrounds, слоты Dark/Light](readme/webui-main-backgrounds-guide.png)
![Web UI: Main Screen Backgrounds, слот Custom](readme/webui-custom-background-guide.png)

## Быстрый старт

1. Подготовьте плату ESP32-4848S040 и питание.
2. Настройте `src/myoptions.h` (плата, язык интерфейса).
3. Выберите окружение PlatformIO `4848S040`.
4. Соберите прошивку и образ LittleFS.
5. Прошейте устройство.
6. Пройдите настройку Wi-Fi при первом запуске.
7. Откройте Web UI по IP-адресу устройства.

Подробная пошаговая инструкция, включая пины, звук и устранение неполадок → [README_4848S040.md](README_4848S040.md).

## Настройка проекта

- Сборка выполняется через [PlatformIO](https://platformio.org/).
- Плата и её пины задаются в `src/myoptions.h` (образец для 4848S040 — `src/myoptions_4848S040.h`).
- Язык интерфейса — `L10N_LANGUAGE` в `src/myoptions.h` (`RU`, `EN` или `PL`); переключение только пересборкой.
- Список станций и сохранённые сети Wi-Fi хранятся как файлы в `data/` и записываются на устройство образом LittleFS.
- Weather API-ключ (OpenWeatherMap) задаётся не в исходниках, а в Web UI (раздел Weather/API) и сохраняется на устройстве.
- AI Layer (необязательно) требует OpenAI-compatible API, ключ, модель и prompt — задаются через Web UI; без них устройство работает как обычное интернет-радио.

Не публикуйте реальные ключи API, пароли Wi-Fi или SSID в конфигурационных файлах, которые попадают в репозиторий.

## Внешний аудиокодек / ЦАП

Рабочий вариант звука для YoRadio — внешний I2S DAC или усилитель, подключаемый к линиям DOUT/BCLK/LRC на заднем разъёме платы. Встроенный моно-ЦАП на плате тоже доступен (включается перемычками), но на практике используется в первую очередь для быстрой проверки платы без дополнительного оборудования, а не как основной сценарий эксплуатации.

Подробности подключения и фото → [README_4848S040.md](README_4848S040.md#контакты-и-подключение).

## AI Layer

AI Layer — необязательный тихий слой поверх музыки. Он не является ассистентом, не ведёт диалог и не стремится заполнять экран текстом: молчание для него — нормальное состояние. Для работы нужны OpenAI-compatible API, ключ, модель и prompt; без них YoRadio остаётся обычным интернет-радио.

## Ограничения beta

- Публично поддерживается только плата ESP32-4848S040; другие board-профили остаются в исходниках, но не входят в поддержку публичной beta.
- Язык интерфейса выбирается при компиляции; переключения RU/EN/PL во время работы нет.
- Выход из Sleep Device (deep sleep) — только кнопкой Reset или переподключением питания; пробуждение касанием не поддерживается.
- Web UI работает только в локальной сети устройства, без HTTPS.
- Рекомендуется внешний ЦАП для полноценного звука; встроенный вариант удобен в первую очередь для проверки платы.

| `src/` | Исходный код прошивки (PlatformIO `src_dir`) |

## Начало работы

- **Готовая прошивка.** Выберите RU, EN или PL в каталоге [`build_bin/4848S040/`](build_bin/4848S040/) и следуйте [инструкции по прошивке](build_bin/4848S040/README.md). Пользователям готовых файлов не нужно вручную заменять системные библиотеки.
- **Сборка из исходников.** Подготовка платы, установка обязательных custom IDF libraries, выбор языка и команды PlatformIO описаны в [инструкции для ESP32-4848S040](README_4848S040.md). Перед сборкой обязательно прочитайте [важные замечания](#важные-замечания-для-сборки-из-исходников).

> Файлы прошивки будут добавлены после финальной сборки beta-релиза.

## Важные замечания для сборки из исходников

- Для source build требуется полный KnownGood-набор из `library!/esp32s3_5_5_2__3_3_6_ai_tls_profile_b_FULL_WORKING_20260603_221741/`. В нём находятся 10 согласованных архивов LwIP, esp_netif, HTTP и mbedTLS/TLS; ранний каталог только с `liblwip.a` и `libesp_netif.a` для текущей beta недостаточен.
- Набор предназначен для PIOArduino `55.03.36`, Arduino-ESP32 `3.3.6` и пакета `framework-arduinoespressif32-libs` `5.5.0+sha.f56bea3d1f` (ESP-IDF 5.5.2). Архивы копируются с заменой в `framework-arduinoespressif32-libs/esp32s3/lib/`, после чего нужно перезапустить PlatformIO, выполнить clean и собрать проект заново.
- Точные имена файлов, пути для Windows/Linux/macOS и порядок установки приведены в разделе [«Обязательные библиотеки ESP-IDF»](README_4848S040.md#обязательные-библиотеки-esp-idf). После переустановки или обновления framework package замену нужно повторить.
- Эта операция нужна только при сборке из исходников. Готовые файлы из `build_bin/` уже собираются с нужным набором библиотек.
- Язык интерфейса задаётся в `src/myoptions.h` через `L10N_LANGUAGE`: `RU`, `EN` или `PL`. Переключения языка во время работы нет.
