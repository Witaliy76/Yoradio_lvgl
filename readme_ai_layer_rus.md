# AI Layer в Yoradio

Author: Witaliy76 - https://github.com/Witaliy76

## Что такое AI Layer
AI Layer — это эксперимент автора по «оживлению» прибора:
тихий семантический слой, который может появляться на фоне музыки и добавлять смысл, когда это уместно.
Он не является ассистентом, не ведёт диалог и не стремится к постоянному присутствию.
Если слой молчит — это корректное состояние и нормальный режим работы.

Устройство остаётся Wi‑Fi интернет‑радио: музыка первична, экран и текст вторичны.

## Поведение и принципы
AI Layer не инициирует события и не влияет на работу системы.
Он появляется эпизодически и не конкурирует с музыкой.
Слабые или неуверенные формулировки не выводятся.

Отсутствие текста в AI Layer не является ошибкой.
При отсутствии входных данных или уверенности вывод просто не формируется.

## Слои AI Layer
AI Layer может отображать несколько независимых строк:

- **Facts** — короткие проверяемые факты о треке или исполнителе.  
- **Interpretation** — мягкая интерпретация атмосферы музыки, без анализа и объяснений.  
- **Moment / Context** — нейтральный контекст прибора (не AI‑слой): короткие системные фразы, не связанные с музыкой.

Каждый слой может быть пустым независимо от других.
Слои не обязаны появляться одновременно и могут отсутствовать большую часть времени.
Moment / Context появляется как нейтральный фон, когда AI‑вывод не сформирован.
Условия вывода Moment / Context:
- есть валидный трек (не системный статус);
- AI включён и активирован;
- prompt загружен;
- для этого трека не было выведено Facts/Interpretation;
- решение уже принято, что LLM молчит по этому треку.
Moment / Context показывается один раз на трек и при выключенном AI или без prompt этот слой молчит.

## Требования и совместимость
AI Layer работает с OpenAI‑compatible API (HTTP/HTTPS).
Поддерживаются публичные и локальные совместимые провайдеры.
Без доступа к провайдеру система продолжает работать как обычное интернет‑радио.
При ошибках сети или таймаутах AI Layer просто не выводит текст и не влияет на работу устройства.

## Получение API key

Для работы AI Layer требуется API key OpenAI‑compatible провайдера.
Можно использовать любой совместимый сервис — публичный или локальный.

Ниже несколько распространённых вариантов.

### DeepSeek
DeepSeek предоставляет OpenAI‑compatible API.

1. Перейдите: https://platform.deepseek.com/
2. Создайте аккаунт или войдите.
3. Сгенерируйте API key в панели управления.
4. Стартовые настройки:
   - API host: `api.deepseek.com`
   - API port: `443`
   - API path: `/v1`

DeepSeek подходит для экспериментов и регулярного использования.
Тарифы и лимиты зависят от вашего аккаунта.

### OpenAI
OpenAI предоставляет эталонный OpenAI API.

1. Перейдите: https://platform.openai.com/
2. Войдите и откройте раздел API keys.
3. Создайте новый API key.
4. Типовые настройки:
   - API host: `api.openai.com`
   - API port: `443`
   - API path: `/v1`

Может потребоваться активный биллинг.

### OpenRouter (опционально)
OpenRouter объединяет несколько OpenAI‑compatible моделей через единый API.

1. Перейдите: https://openrouter.ai/
2. Создайте аккаунт.
3. Сгенерируйте API key.
4. Типовые настройки:
   - API host: `openrouter.ai`
   - API port: `443`
   - API path: `/api/v1`

OpenRouter может предоставлять небольшой бесплатный лимит для тестов
в зависимости от текущей политики платформы.
Проверьте актуальные лимиты на их сайте.

### Примечания

- Проект Yoradio не связан с перечисленными провайдерами.
- Доступность API, цены и лимиты определяются провайдером.
- Если API key не задан, AI Layer молчит, а устройство работает в обычном режиме.
- AI Layer не выполняет запросы автоматически и не потребляет API, пока не появляется подходящий контекст.

После получения API key и prompt можно перейти к настройке слоя в WebUI.

## Настройка AI Layer в WebUI
Раздел настроек расположен в WebUI на вкладке AI Layer.

![AI Layer settings](settings_ai.jpg)

Ниже показан реальный экран настроек AI Layer:

Параметры на экране:

- **AI enabled** — включает или отключает AI Layer.  
  - Включено: слой может формировать вывод.  
  - Отключено: слой молчит, поведение системы не меняется.  
  - Если выключено — все остальные параметры игнорируются.

- **API host** — адрес сервера OpenAI‑compatible.  
  - Пример: `api.deepseek.com`, `api.openai.com`.  
  - Если не задан — запросы не отправляются, слой молчит.

- **API port** — порт сервера.  
  - Обычно `443` для HTTPS.  
  - Если не задан — соединение не выполняется.

- **API path** — путь API.  
  - Пример: `/v1`.  
  - Если не задан — запросы не отправляются.

- **Timeout (ms)** — таймаут запроса в миллисекундах.  
  - Меньшее значение снижает ожидание ответа.  
  - Если не задан — используется системное значение по умолчанию.

- **API key** — ключ доступа к провайдеру.  
  - Если отсутствует или неверен — запросы отклоняются, слой молчит.  
  - Отсутствие ключа не влияет на работу радио.

- **Model** — модель провайдера.  
  - Пример: `deepseek-chat`, `gpt-4o-mini`.  
  - Если не задана — запросы не выполняются.

- **Prompt file** / **Upload Prompt File** — загрузка файла prompt.  
  - После выбора файла отображается статус **Loaded (… bytes)**.  
  - Если prompt не загружен — AI Layer полностью молчит.

- **Apply** — сохраняет параметры и применяет их.  
  - Без нажатия параметры не сохраняются.

Язык вывода задаётся текстом prompt: если нужен русский вывод, используйте RU‑prompt, для английского — EN‑prompt.
Начинайте prompt на нужном языке — это и будет языком ответа.
Язык интерфейса влияет только на строки Moment / Context.

## Prompt-файл
Prompt задаёт правила и тональность вывода.
Он загружается через кнопку **Upload Prompt File** в WebUI.
Примеры prompt‑файлов из каталога `ai/`: [ai/ai_prompt_ru.txt](ai/ai_prompt_ru.txt), [ai/ai_prompt_en.txt](ai/ai_prompt_en.txt).
Подробнее о структуре prompt: [readme_ai_prompt_explained_rus.md](readme_ai_prompt_explained_rus.md).
Если вы прошиваете SPIFFS заранее, поместите prompt в `data/ai/ai_prompt.txt`
(можно просто скопировать один из файлов из `ai/`).
Либо загрузите prompt позже через WebUI — результат будет тем же.

Правила работы:

- Новый prompt заменяет предыдущий.  
- После загрузки должен появиться статус **Loaded (… bytes)**.  
- **Нет prompt → AI Layer полностью молчит.**  
- Отсутствие prompt не считается ошибкой.  
- Fallback‑тексты не используются.

Максимальный размер prompt‑файла: 8192 байта (8 КБ).

## Примеры вывода
- Facts: `Alphaville — Forever Young (1984).`  
- Interpretation: `Тёплая, спокойная атмосфера, без напряжения.`  
- Moment: `Всё идёт своим темпом.`  
- Нет вывода: `—` (экран без строк AI Layer, это корректно).

## Как понять, что AI Layer работает корректно
AI Layer считается настроенным, если:

- Он включён в WebUI и параметры сохранены через **Apply**.  
- Prompt загружен и отображается статус **Loaded (… bytes)**.  
- Иногда появляются строки Facts или Interpretation, а в остальное время слой молчит.

Если слой молчит постоянно, проверьте: включение AI Layer, наличие prompt, API key и model.
Для обычной эксплуатации дополнительная диагностика не требуется.
Для разработчиков и отладки можно включить `AI_LAYER_DEBUG` в `myoptions.h` (значение `1`).
Даже при полностью настроенном слое отсутствие вывода остаётся допустимым состоянием.

AI Layer не делает устройство «умным» — он делает его чуть более живым, когда это уместно.
