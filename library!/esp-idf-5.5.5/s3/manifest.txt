RESTART_IN_VSYNC policy
-----------------------
CONFIG_LCD_RGB_RESTART_IN_VSYNC = n.

libesp_lcd.a in this pack is built with the automatic per-VSYNC RGB panel
restart DISABLED (esp_lcd/rgb/esp_lcd_panel_rgb.c:1153-1166).  YoRadio's
Display layer owns RGB resynchronisation instead and performs a single
bounded restart after each flash-writing operation.  Stock esp_lcd cannot be
substituted here without reintroducing the continuous-restart behaviour.

mbedTLS wrap requirement
------------------------
libmbedtls_2.a in this pack REQUIRES these 12 GNU --wrap link options.  They
are applied automatically by yoradio_build.py, and only when all seven
archives validate.  Linking this pack without them, or applying them without
this pack, is not a supported configuration.

    -Wl,--wrap=mbedtls_ssl_close_notify
    -Wl,--wrap=mbedtls_ssl_free
    -Wl,--wrap=mbedtls_ssl_handshake_client_step
    -Wl,--wrap=mbedtls_ssl_handshake_server_step
    -Wl,--wrap=mbedtls_ssl_read
    -Wl,--wrap=mbedtls_ssl_send_alert_message
    -Wl,--wrap=mbedtls_ssl_session_reset
    -Wl,--wrap=mbedtls_ssl_setup
    -Wl,--wrap=mbedtls_ssl_tls13_handshake_client_step
    -Wl,--wrap=mbedtls_ssl_tls13_handshake_server_step
    -Wl,--wrap=mbedtls_ssl_write
    -Wl,--wrap=mbedtls_ssl_write_client_hello

(log_printf and longjmp are wrapped by the stock framework itself and are not
part of this pack's requirement.)

How these archives are used
---------------------------
They are NOT copied into the PlatformIO framework package.  yoradio_build.py
prepends this directory to the linker search path, so the seven -l names
resolve here instead of in
  <platformio>/packages/framework-arduinoespressif32-libs/esp32s3/lib/
which stays byte-unchanged.  Validation is atomic: 7/7 SHA256 matches enable
the overlay and the 12 wraps together; anything less disables both and the
build falls back to the complete stock library set with a warning.

This file is the human-readable provenance record.  The SHA256 table that the
build actually enforces is embedded in yoradio_build.py, so that a modified
overlay cannot certify itself by editing this manifest.
